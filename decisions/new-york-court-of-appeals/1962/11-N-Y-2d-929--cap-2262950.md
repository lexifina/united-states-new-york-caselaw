# Jung v. State

## Majority

Motion to dismiss appeal [for failure to file an undertaking and return on appeal] granted and appeal dismissed, with costs and $10 costs of motion, unless, within 10 days, appellants serve and file an undertaking on appeal, pay $10 costs and file the return on appeal, in which events motion denied.
