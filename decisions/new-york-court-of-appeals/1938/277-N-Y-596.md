# People v. Hughes

## Majority

Motion for reargument granted as follows: The question as to the power of this Court to reduce the sentence under section 543 of the Code of Criminal Procedure has never been decided by this Court. The point is now raised and we would like to hear oral argument. Case set down for March 14, 1938. (See 277 N. Y. 531.)
